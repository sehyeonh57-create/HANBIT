    v0.5 그래픽 첫걸음 · 화면, 버튼, 그림
    기존 출력은 글자를 결과 창에 보여 줍니다. 그래픽 명령은 실행 결과 안에 별도의 프로그램 화면을 만들어요. 좌표 (0, 0)은 왼쪽 위이고, 가로 좌표 x는 오른쪽으로, 세로 좌표 y는 아래로 갈수록 커집니다. 크기와 위치의 단위는 화면의 논리 픽셀입니다. 모바일에서는 화면이 자동 축소됩니다.
    1. 화면 만들기
    먼저 창을 만든 후, 화면 안에 이름을 가진 요소를 배치합니다. 이름은 나중에 글자나 위치를 변경할 때 사용해요.
    창("첫 화면", 320, 220)
글자("인사", "안녕하세요!", 20, 30)
    실습: 글자의 위치를 (40, 80)으로 바꾸고 실행해 보세요.
    2. 클릭 이벤트
    버튼을 누를 때마다 마지막 인수에 적은 함수가 실행됩니다. 함수 이름은 따옴표로 감싸고, 함수는 매개변수 없이 작성하세요. 함수 바깥에서 선언한 변수의 값을 함수에서 변경할 수 있습니다. 함수 안에서 변수 명령으로 새로 선언한 값은 함수 내부에만 저장돼요.
    변수 점수 = 0
함수 누르기()
    점수 = 점수 + 1
    글자변경("점수판", 점수)
끝
창("클릭 게임", 320, 220)
글자("점수판", 점수, 20, 20)
버튼("누름", "점수 올리기", 20, 80, 200, 55, "누르기")
    실습: 한 번 클릭할 때마다 점수가 2씩 증가하도록 수정해 보세요.
    3. 이미지와 색상
    그림은 기본 제공 이미지 이름 "별", "하트", "사과"를 사용하거나 아래에서 내 이미지를 등록할 수 있습니다. 등록한 파일은 서버로 전송하지 않고 현재 탭에서만 사용합니다. 코드 저장 파일에는 이미지가 포함되지 않으므로 새로고침 후 다시 등록하세요.
    실습: 별을 하트로 바꾸고 배경색도 변경해 보세요.
    등록 후 사용할 그림 이름이 표시됩니다.
    그래픽 명령어 사전
    이 그래픽 입문 과정은 별도 자유 실습이며 기존 필수 15단계와 45문제에는 영향을 주지 않습니다.
    한빛 문법 안내
    • 출력 "안녕!" : 글자나 계산 결과 출력
    • 변수 돈 = 1000 : 변수 만들기 / 돈 = 돈 - 500 : 값 변경
    • 만약 돈 >= 500 이라면 : 조건문. 아니면은 선택, 마지막에 끝
    • 반복 5번 : 반복문. 마지막에 끝
    • 변수 번호 = 무작위(1, 10) : 1~10 중 정수 뽑기
    • 변수 이름 = 입력("이름은?") : 글자 입력 / 숫자(이름) : 숫자로 변환
    • + - * / % == != >= <= > < 및 그리고 또는 아니다 사용 가능
    • # 설명 : 줄 전체 또는 코드 뒤 주석. 문자열은 큰따옴표나 작은따옴표로 감싸세요.
    • 함수 더하기(가, 나) … 반환 가 + 나 … 끝 : 값을 받아 결과를 돌려주는 함수. 출력 더하기(2, 3)으로 호출합니다. 함수 안에서 만든 변수는 함수 내부에서만 사용합니다.
    • 변수 가방 = ["사과", "지도"] : 목록 만들기. 가져오기(가방, 1)은 첫 번째 항목입니다. 순서는 1부터 시작합니다.
    • 길이(가방) : 항목 수. 가방 = 추가(가방, "열쇠"), 가방 = 제거(가방, 1), 가방 = 바꾸기(가방, 1, "책") : 새 목록을 만들어 반환하므로 변수에 다시 저장해야 합니다.
    • 현재날짜(), 현재시간(), 시(), 분(), 초(), 년(), 월(), 일() : 실행 시작 시점의 기기 날짜와 시간. 경과초()는 실행 후 지난 초를 반환합니다.

    실행하면 아무것도 안 나와요. 한빛에서 변수에 값을 저장하는 것만으로는 화면에 표시되지 않아요. 출력 명령을 추가해 보세요.
    들여쓰기는 무엇인가요? 조건문이나 반복문 안의 코드를 오른쪽으로 밀어 읽기 편하게 만드는 방법입니다. 한빛은 끝 명령으로 구역을 구분하며, Tab 키로 공백 4개를 넣을 수 있어요.
    코드를 저장하고 싶어요. 코드 저장을 누르면 .hanbit 파일이 저장됩니다. 파일 열기로 다시 불러올 수 있어요. 튜토리얼 진행률은 가능한 경우 현재 브라우저에 저장되지만, v0.4부터 작성 중인 코드도 가능한 경우 브라우저에 임시 저장됩니다. 중요한 코드는 파일로 따로 저장하세요.
    게임이나 앱도 만들 수 있나요? 현재는 글자로 결과를 보여 주는 프로그램을 만들 수 있습니다. 사용자 정의 함수와 목록은 지원합니다. v0.5부터 그래픽 창, 글자, 버튼, 그림을 사용할 수 있습니다.
